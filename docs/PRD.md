## 1. 产品概述

### 1.1 背景与定位
很多业务系统都需要"在一张底图上标出设备的位置"——安防在楼层平面图上布摄像头/门禁/消防栓，光伏在电站图上布逆变器，智能家居把设备摆进房间。这类功能交互相似，却被各项目重复开发。

本产品把它抽象为一个**开箱即用的前端组件**，以 npm 包发布，接入方安装后传入设备与底图，即可获得完整的"拖拽打点"能力，并拿到标准化的点位数据。

### 1.2 一句话价值
> 让"在图上标设备位置"从每个项目重复造轮子，变成装个包就能用。

### 1.3 名词解释

| 名词 | 含义 |
|------|------|
| 设备（实例） | 一台具体的、唯一的设备，有名称和图标。例：编号 cam-01 的"大厅摄像头" |
| 底图 | 中间用于标注的背景图片（如楼层平面图） |
| 点位 | 一个设备被摆放在底图上的位置标记 |
| 打点 | 把设备摆到底图上某个位置的动作 |
| 回显 | 把之前保存的点位数据重新加载、在底图上还原出来 |

## 2. 目标用户与使用场景

| 角色 | 是谁 | 核心诉求 |
|------|------|---------|
| 接入者 | 引入本包的前端开发 | 传入设备和底图，少写代码就拿到打点能力和结果数据 |
| 操作者 | 实际拖拽的人（运维 / 施工 / 规划人员） | 直观地把设备摆到底图上正确的位置并能调整 |

**典型场景：** 在楼层平面图上布置摄像头、门禁、消防栓；在光伏电站图上布置逆变器。

## 3. 需求范围

### 3.1 本期范围（In Scope）
- 左侧设备列表（平铺，不分组）
- 中间底图画布
- 从列表拖设备到底图打点
- 在底图上拖动点位、移动位置
- 删除点位
- 列表与底图的高亮联动
- 点位上方显示设备名称
- 标准化的点位数据输出与回显
- 底图缩放 / 平移（滚轮缩放、拖空白平移、双击复位；可通过 `zoomable` 关闭）
- 只读展示画布下的点位聚合（cluster）：密集点位合并显示为数字圆点，缩放后自动拆散

### 3.2 不在本期范围（Out of Scope，未来迭代）
- 同一设备放置多个点位
- 点位属性弹窗 / 详情编辑
- 点位按设备状态变色（在线/离线/告警）
- 后端存储、接口对接、多人协作
- 撤销 / 重做
- 左侧设备按分类分组
- 移动端 / 触摸操作
- 打点编辑器（`readonly=false`）下的点位聚合
- 选中/定位某设备时，若被聚合遮住自动展开并对准它
- 聚合圆点按设备状态（如告警）着色作为组件内置能力（由 `#cluster` 插槽把簇成员交给接入方自行判断）
- 聚合半径、最小聚合数量的可配置化（当前为内部固定合理默认值）

### 3.3 关键约束
- **仅支持桌面浏览器（鼠标操作）**，本期不考虑触摸 / 移动端。
- **组件不负责数据持久化与后端通信**：只负责"产出点位数据"和"回显点位数据"，存库由接入方完成。
- 技术形态为 Vue 3 组件。
- 设备图标与底图均为**图片 URL**，图片资源由接入方放置在项目目录中。

## 4. 界面结构

```
┌──────────────┬─────────────────────────────────┐
│  设备列表      │                                 │
│              │            底图画布               │
│  □ 消防栓-01  │                                 │
│  □ 门禁-东门  │        [图标] 摄像头-大厅          │
│  ▣ 摄像头-大厅 │          ▲ 点位摆在底图上          │
│  ▣ 逆变器-A区 │                                 │
│   …（可滚动）  │        [图标] 逆变器-A区          │
│              │                                 │
└──────────────┴─────────────────────────────────┘
      左侧                      中间
   □ 未放置  ▣ 已放置
```

- **左侧**：设备列表，平铺展示；区分"未放置 / 已放置"两种状态；列表过长可滚动。
- **中间**：底图画布，承载底图与所有点位。

## 5. 核心概念与状态流转

**铁律：一个设备实例，在底图上最多只有一个点位。**

设备状态流转：

```
                ┌──────── 删除点位 ────────┐
                ▼                          │
            ┌────────┐   拖入画布      ┌────────┐
            │ 未放置  │ ───────────▶ │ 已放置  │
            └────────┘               └────────┘
                                      │   ▲
                       再次拖入 / 画布内拖动│   │（位置改变，仍是已放置）
                                      └───┘
                                          │
                              点击设备或点位 → 高亮（3 秒后自动取消）
```

## 6. 功能需求

### F1 从列表拖设备到底图（新建点位）· P0
- **描述**：操作者按住左侧"未放置"的设备拖到底图上松手，该位置出现设备图标点位。
- **规则**：放置后，左侧对应设备变为"已放置"状态（仍显示在列表中，仅视觉区分）。
- **验收**：拖放后底图出现点位，左侧状态同步变化。

### F2 已放置设备再次拖入（移动，非新增）· P0
- **描述**：对一个"已放置"的设备，再次从左侧拖到底图。
- **规则**：**不会新增第二个点位**，而是把它已有的点位移动到新落点。坚守"一设备一点位"。
- **验收**：操作后该设备在底图上仍只有一个点位，位置更新为新落点。

### F3 在底图内拖动点位（移动）· P0
- **描述**：直接按住底图上的点位拖动，松手即定位。
- **验收**：点位跟随鼠标移动，松手后停在落点。

### F4 删除点位 · P0
- **描述**：点位图标**右上角的小"×"按钮**用于删除该点位。
- **规则**：
  - "×"按钮**平时隐藏，仅在鼠标悬停该点位、或该点位被选中时显示**（避免点位密集时画面杂乱、误触）。
  - 删除**不需要二次确认**，点击即删。
  - 删除后，左侧对应设备恢复"未放置"，可重新拖入。
- **验收**：悬停/选中出现"×"，点击后点位消失、左侧状态回退。

### F5 列表 ↔ 底图 高亮联动 · P0
- **描述**：点击左侧"已放置"的设备，底图上对应点位高亮（如放大 / 描边）。
- **规则**：
  - 高亮在 **3 秒后自动取消**。
  - 点击左侧"未放置"的设备：**无操作**。
- **验收**：点击已放置设备，对应点位高亮并在 3 秒后恢复。

### F6 点位名称显示 · P0
- **描述**：点位图标的**上方常显**该设备的名称。
- **规则**：名称过长时限定宽度、超出省略。
- **验收**：每个点位上方显示对应设备名称。

### F7 左侧"已放置"状态的视觉区分 · P0
- **描述**：左侧已放置的设备需与未放置的有**明显视觉区分**（如置灰 / 打勾 / "已放置"角标，具体样式待 UI）。
- **验收**：操作者能一眼看出"还有哪些设备没摆"。

### F8 拖拽过程的视觉反馈 · P1
- **描述**：拖拽过程中给出反馈（如跟随光标的图标预览、可放置区域提示）。
- **验收**：拖拽时有明确的视觉跟随。

### F9 底图缩放 / 平移 · P1
- **描述**：底图过大或需要精细打点时，可放大查看、拖动浏览。
- **规则**：
  - **滚轮缩放**，以光标位置为焦点；缩放下限为"适应画布"（1×），上限 6×。
  - 放大后**按住空白区域拖动平移**；平移被限制在底图范围内，不留空白。
  - **双击空白区域复位**到适应画布。
  - 缩放/平移不改变点位数据：坐标仍以归一化比例（0~1）存储，缩放后点位自动跟随。
  - 由 `zoomable` 控制开关（默认开启）；关闭时滚轮/拖动/双击均不生效，并复位视图。
- **验收**：滚轮可缩放、放大后可平移、双击复位；`zoomable=false` 时以上交互全部禁用。

### F10 点位聚合（cluster）· P1
- **描述**：只读展示画布上点位密集时，图标会互相重叠；开启聚合后，密集点位合并显示为一个带数字的圆点，缩放到点位间距足够大时自动拆散为独立图标。
- **规则**：
  - 由 `cluster` prop 开启（默认关闭，向后兼容）；**仅在 `readonly=true` 时生效**，打点编辑器（`readonly=false`）即使传入也不生效。
  - 聚合阈值由组件内部按运行时实际生效的点位图标像素尺寸自动换算，不对外暴露可配置项。
  - 点击聚合圆点：画布自动放大、平移，使该簇完整、居中进入可视区域；同时抛出 `cluster-click` 事件。
  - 聚合圆点默认样式为"主题色圆形 + 数字"，可通过 `#cluster` 插槽完全自定义（作用域参数含簇内成员的设备与点位数据），例如按业务状态（告警等）着色——该判断逻辑由接入方实现，组件本身不理解设备状态。
  - 平移画布不影响聚合分组，只有缩放比例变化才会重新分组。
- **验收**：密集点位默认合并为数字圆点；放大到间距足够后自动拆散，缩小回去重新合并；点击圆点画布聚焦且不误触发双击复位；`readonly=false` 时聚合不生效。

## 7. 数据需求 ⭐（重点）

> 组件不直接连后端。它的数据职责只有两件：**对外输出**最新点位数据（供接入方存库）、**接收回显**已保存的点位数据（在底图上还原）。输入与输出采用**同一套结构**，可直接来回传递。

### 7.1 设计原则
1. **坐标用相对比例（0~1），不用像素。** 记录"点位相对底图的百分比位置"，这样无论底图在不同屏幕 / 容器里显示多大，点位都落在底图上同一相对位置，不会错位；也为未来的缩放功能打好基础。
2. **结构对称、可回环。** 存进数据库的就是组件吐出来的；读出来原样传回组件即可还原。
3. **以设备 id 为主键。** 因"一设备一点位"，无需为点位单独编号，用 `deviceId` 即可唯一定位一个点位。

坐标含义：

```
(0,0) ──────────────► x 向右 (1,0)
  │
  │            底  图
  ▼
y 向下
(0,1)                        (1,1)
```

### 7.2 组件输入的数据

**① 设备清单（决定左侧列表）**
```json
[
  { "id": "fire-hydrant-01", "name": "消防栓-1F东",  "icon": "/device-icons/fire-hydrant.png" },
  { "id": "access-door-01",  "name": "门禁-东门",    "icon": "/device-icons/door.png" },
  { "id": "camera-01",       "name": "摄像头-大厅",   "icon": "/device-icons/camera.png" },
  { "id": "inverter-01",     "name": "逆变器-A区",    "icon": "/device-icons/inverter.png" }
]
```

**② 底图（中间背景图）**
```json
"/floor-plans/building-a-1f.png"
```

**③ 已保存的点位（用于回显，结构同输出）**
```json
[
  { "deviceId": "camera-01",   "x": 0.324, "y": 0.581 },
  { "deviceId": "inverter-01", "x": 0.760, "y": 0.402 }
]
```

### 7.3 组件输出的数据（供保存）
每当发生**新建 / 移动 / 删除**，组件对外提供**最新的完整点位数组**（结构与 7.2-③ 完全一致）：
```json
[
  { "deviceId": "camera-01",   "x": 0.300, "y": 0.620 },
  { "deviceId": "inverter-01", "x": 0.760, "y": 0.402 },
  { "deviceId": "access-door-01", "x": 0.150, "y": 0.880 }
]
```
接入方拿到这份数组即可保存到后端。

### 7.4 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| `devices[].id` | string | 是 | 设备唯一标识，作为点位的关联键 |
| `devices[].name` | string | 是 | 设备名称，显示在点位图标上方 |
| `devices[].icon` | string | 是 | 设备图标的图片 URL |
| `devices[].type` | string | 否 | 设备分类（预留字段，本期不用于分组） |
| `background` | string | 是 | 底图图片 URL |
| `placements[].deviceId` | string | 是 | 关联的设备 id（唯一，对应"一设备一点位"） |
| `placements[].x` | number | 是 | 横向相对位置，取值 0~1（建议保留 3~4 位小数） |
| `placements[].y` | number | 是 | 纵向相对位置，取值 0~1 |

### 7.5 完整示例（输入 → 操作 → 输出）

接入方传入：设备清单（4 个）、底图、已保存点位（2 个：摄像头、逆变器）。
操作者：把"门禁-东门"拖入底图，并微调了摄像头位置，删除了……（无）。
组件输出：
```json
[
  { "deviceId": "camera-01",      "x": 0.300, "y": 0.620 },
  { "deviceId": "inverter-01",    "x": 0.760, "y": 0.402 },
  { "deviceId": "access-door-01", "x": 0.150, "y": 0.880 }
]
```

### 7.6 数据可见性（满足"我能看到数据"）
- 组件在**每次点位变化后**，都会对外给出最新的完整点位数据。
- 配套的**演示页面会把这份 JSON 实时显示在界面上**，方便你随时查看、复制，确认数据格式与内容。

### 7.7 后端存储建议（参考，非组件职责）
组件只产出上面的数组。若你要存库并支持多张底图，建议表结构如下（仅供参考）：

| 字段 | 说明 |
|------|------|
| `id` | 主键 |
| `map_id` | 底图 / 场景标识。**组件不产生**，由接入方按"当前底图"补充，用于区分多张图 |
| `device_id` | 对应 `placements[].deviceId` |
| `pos_x` / `pos_y` | 对应 `x` / `y`（0~1） |
| `updated_at` | 更新时间 |

保存策略可二选一：整表覆盖（每次用组件吐出的完整数组覆盖该底图下的记录），或按 `device_id` 做 upsert（有则更新坐标、无则插入）。

## 8. 边界与异常处理

| 情况 | 规则 |
|------|------|
| 点位拖到底图边缘 / 外部 | 限制在底图范围内，不允许拖出 |
| 多个点位重叠 | 允许重叠；后放置的在上层，被压住的点位仍可被选中 |
| 设备名称过长 | 限定宽度，超出显示省略号 |
| 底图未传 / 加载失败 | 显示占位提示，不报错、不白屏 |
| 无任何设备 / 无任何点位 | 显示空状态引导文案 |
| 左侧设备数量很多 | 列表区域可滚动 |
| 回显数据中含底图上不存在或设备清单中没有的 id | 忽略该条，不影响其余点位渲染 |

## 9. 交互细节补充
- **删除"×"显示时机**：悬停点位 或 点位被选中时显示；其余时间隐藏。
- **删除确认**：无需二次确认，点击即删。
- **高亮取消**：高亮后 3 秒自动取消。
- **点击未放置设备**：无操作。
- **缩放/平移**：滚轮以光标为焦点缩放（1×~6×）、放大后拖空白平移、双击空白复位；可由 `zoomable` 关闭。
- **仅桌面鼠标**：所有拖拽基于鼠标，不考虑触摸。

---

## 10. 验收标准（概要）
1. 三种打点路径（F1 拖入 / F2 再拖 / F3 画布拖动）结果一致：同一设备在底图上**始终只有一个点位**。
2. 删除点位后，左侧对应设备恢复"未放置"，可重新拖入。
3. 点击左侧已放置设备，对应点位明显高亮，并在 3 秒后自动恢复。
4. 每个点位上方正确显示对应设备名称。
5. 任意点位变化后，组件对外输出的点位数据与界面一致；将该数据回传可原样还原。
